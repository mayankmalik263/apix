# APIx — working rules

## Ponytail: always on
The `ponytail` skill (installed as the `ponytail` plugin) is ACTIVE ON EVERY
RESPONSE for this project, at intensity **full**, without needing to be
invoked. Climb the ladder before writing code: does it need to exist → does it
already exist here → stdlib → native → installed dependency → one line → the
minimum that works. Shortest working diff wins. Code first, then at most three
lines of what was skipped and when to add it.

Off only if the user says "stop ponytail" or "normal mode".

Never simplify away: the compliance gate, the 7-status vocabulary, Bronze
immutability, or anything a MoSPI judge would ask us to defend.
